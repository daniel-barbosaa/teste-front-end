# Teste Econverse — Desenvolvedor Front-End

**Projeto publicado:** [Acessar aplicação](https://teste-front-end-rust.vercel.app)

## Tecnologias

- React
- TypeScript
- Vite
- Sass
- Swiper
- Yarn

## Requisitos

Antes de começar, certifique-se de ter instalado:

- [Node.js](https://nodejs.org/)
- [Yarn](https://yarnpkg.com/)

## Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/daniel-barbosaa/teste-front-end.git
```

Entre na pasta do projeto:

```bash
cd teste-front-end
```

### 2. Instale as dependências

```bash
yarn
```

### 3. Execute em desenvolvimento

```bash
yarn dev
```

Acesse o endereço exibido no terminal, geralmente `http://localhost:5173`.

### 4. Compile o projeto

```bash
yarn build
```

## Funcionalidades

- Exibição de produtos consumidos da API fornecida pela Econverse.
- Vitrines de produtos com navegação por carrossel.
- Modal com informações do produto selecionado.
- Layout adaptado para diferentes tamanhos de tela.
